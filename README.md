# Music App 🎵

A full-stack music management application built using the **MERN stack**. The app allows users to manage songs, view statistics, and perform CRUD operations in real-time.

## Features

### Backend
- Built with **Node.js**, **Express**, **MongoDB**, **Sycodio**, and **JavaScript**.
- REST API supporting:
  - **CRUD Operations**: Create, Read, Update, and Delete songs.
  - **Statistics**: Insights into total songs, artists, albums, genres, and more.
- Deployed on **Render** for seamless access.

### Frontend
- Developed with **React**, **TypeScript**, **Tailwind CSS**, **ShadCN UI**, and **Zustand** for state management.
- Key features:
  - Real-time updates without page reloads.
  - Filtering by genre.
  - Display of detailed statistics about songs, artists, albums, and genres.

## Technologies Used

### Backend
- **Node.js**: Server-side JavaScript runtime.
- **Express**: Web framework for building RESTful APIs.
- **MongoDB**: NoSQL database for storing song data.
- **Sycodio**: For enhanced functionality and integration.

### Frontend
- **React**: Component-based library for building user interfaces.
- **Tailwind CSS**: Utility-first CSS framework.
- **ShadCN UI**: Modern UI components.
- **Zustand**: Lightweight state management library.
- **TypeScript**: Type-safe JavaScript.

### Deployment
- **Backend**: Hosted on **Render**.
- **Frontend**: Integrated and functional with real-time API calls.
